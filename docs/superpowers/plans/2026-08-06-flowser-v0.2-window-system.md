# Flowser v0.2 Window System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a responsive floating browser window with resize, maximize/restore, minimize-to-bubble, a responsive toolbar/menu, persistent state, and foreground-service controls.

**Architecture:** Refactor the current monolithic overlay service into focused pure-Kotlin models plus Android controllers. Geometry and state transitions remain testable without Android Views; `FloatingBrowserService` composes the browser, window, toolbar, bubble, persistence, and notification controllers.

**Tech Stack:** Kotlin, Android SDK 26-35, WebView, WindowManager overlays, SharedPreferences, JUnit 4, GitHub Actions with Java 17 and Gradle 8.7.

## Global Constraints

- Keep package name `com.flowser.app`.
- Keep minimum SDK 26 and target SDK 35.
- Support phone and tablet layouts; Samsung tablet is the primary physical test device.
- Keep one WebView session and one floating window only.
- Preserve the same WebView instance during minimize/restore.
- Minimum window size is 280 dp by 320 dp.
- Bubble size is 56 dp; resize handle touch area is 32 dp.
- Compact toolbar activates below 420 dp width.
- Zoom range is 50-200 percent, step 10, reset 100.
- No new third-party runtime dependencies.
- Every task ends with unit/build verification and a focused commit.

- [ ] **Step 3: Refactor service into composition root**

On first OPEN:

1. Load/clamp saved state.
2. Create browser controller and load requested or saved URL.
3. Create toolbar and window controllers.
4. Enter foreground mode.
5. Show window or bubble based on requested command/state.

On repeated OPEN: load the new URL in the same browser session and restore window.

On MINIMIZE: hide window, preserve WebView, show bubble, persist state.

On RESTORE: hide bubble and restore pre-minimize mode.

On CLOSE: destroy bubble, window, toolbar, WebView, notification, and service.
